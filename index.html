Undo/redo editor

Every edit pushes the old text onto the undo stack. Undo and redo move text between two stacks, last in, first out.

      The rules
      • Edit: push the current text onto Undo, then empty Redo.
      • Undo: push the current text onto Redo, then pop Undo into the document.
      • Redo: push the current text onto Undo, then pop Redo into the document.
      • Push, pop and peek each take constant time, O(1). Shortcuts: Ctrl/Cmd+Z and Ctrl/Cmd+Y.
